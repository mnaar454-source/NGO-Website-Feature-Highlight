# NGO Website Feature Highlight (Task 4)

## AI Web Development Internship – InAmigos Foundation

### Project Overview
This repository contains the Task 4 submission for the AI Web Development Internship at InAmigos Foundation. The project presents a professionally designed Figma layout that highlights the essential features of an NGO website. The design focuses on creating an engaging, user-friendly, and visually appealing interface that supports nonprofit organizations in achieving their mission.

### Key Features
- Donation Section
- Volunteer Registration
- Impact Showcase
- Testimonials
- Campaigns & Events

### Design Objectives
- Create a clean and intuitive user interface.
- Improve user engagement and accessibility.
- Present NGO activities and impact effectively.
- Encourage donations and volunteer participation.
- Follow modern UI/UX design principles.

### Tools Used
- Figma
